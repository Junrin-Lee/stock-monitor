# 📈 Stock Monitor 版本历史

本目录包含 Stock Monitor 项目的详细版本历史文档。

## 📂 版本文档结构

### 🚀 Major Versions (v5.x)

#### 最新版本
- **[v9.1](v9.1.md)** - 🛡️ 数据安全加固与多市场时区增强（原子写入、竞态修复、节假日日历、HKEX收盘竞价）⭐ 当前版本
- **[v9.0](v9.0.md)** - 📈 Sparkline走势迷你图与盘前盘后行情（Unicode方块趋势图、多周期图表、集合竞价支持）
- **[v8.1](v8.1.md)** - 🚀 跨平台发布自动化系统（GoReleaser多平台构建、GitHub Actions CI/CD、Homebrew支持、Makefile增强）
- **[v8.0](v8.0.md)** - 📊 板块市场查看功能（地域/行业/概念板块、实时行情、排序优化、告警追踪）
- **[v7.1](v7.1.md)** - 🔔 告警频率编辑增强（编辑流程扩展、频率类型转换、智能状态重置）
- **[v7.0](v7.0.md)** - 🏗️ 架构重构（模块化 internal/ 包、15 独立包、40+ 单元测试、清晰分层）
- **[v6.0](v6.0.md)** - 🔔 股票告警系统（频率控制、批量操作、跨平台通知）
- **[v5.8](v5.8.md)** - 📊 结构化日志系统（zap 集成、按天轮转、i18n支持）
- **[v5.7](v5.7.md)** - 🏷️ 自选标签分组系统（分组UI、位置记忆、边界停留）
- **[v5.6](v5.6.md)** - 🔍 搜索视图增强（实时分时图、自动刷新、临时采集）
- **[v5.5](v5.5.md)** - 🏷️ 自选股票市场标签体系（自动市场识别、市场标签显示、数据自动迁移）
- **[v5.4](v5.4.md)** - 🔧 港股换手率数据修复（东方财富API集成、单元测试增强）
- **[v5.3](v5.3.md)** - 🛡️ 关键修复与智能数据采集增强（自选列表死锁修复、多市场时区增强、智能Worker系统）
- **[v5.2](v5.2.md)** - 📊 可定制表格列与用户体验升级（灵活列配置、简洁/详细模式、向后兼容）
- **[v5.1](v5.1.md)** - 🌍 多市场支持与关键修复（美股、港股盘中数据、Yahoo API、单元测试）
- **[v5.0](v5.0.md)** - 架构现代化与核心功能重构
