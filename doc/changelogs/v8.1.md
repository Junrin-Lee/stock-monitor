## 🎯 版本概述 | Version Overview

v8.1 是在 v8.0 基础上的**基础设施和发布流程增强**版本，实现了完整的**跨平台发布自动化系统**，包括 GoReleaser 多平台构建、GitHub Actions CI/CD 流程、Homebrew 公式管理、以及增强的 Makefile 发布命令。用户现在可以通过多种方式便捷地安装和升级 Stock Monitor。

**Major Points:**
- 🚀 **GoReleaser 配置** - 支持 Windows/macOS/Linux 多平台构建（amd64/arm64）
- 🔄 **GitHub Actions CI/CD** - 推送 tag 自动触发构建和发布流程
- 🍺 **Homebrew 支持** - macOS 用户可通过 `brew install` 安装
- 📦 **多格式打包** - 支持 zip、tar.gz、deb、rpm、dmg 等格式
- 🔧 **增强 Makefile** - 新增 release-check、release-snapshot、release-dry-run 命令
- 📝 **版本信息** - 二进制文件包含版本、提交哈希、构建时间信息
- ✅ **100% 兼容 v8.0** - 所有现有功能完整保留

**功能演进**:
```
v7.0: 架构重构 (internal/ 包化，40+ 单元测试)
v7.1: 告警频率编辑 (支持频率修改)
v8.0: 板块市场查看 + 排序优化 + 告警追踪
v8.1: 跨平台发布自动化 + CI/CD 流程 ⭐ 当前
```

### 1. GoReleaser 多平台构建 | GoReleaser Multi-Platform Builds

**支持的平台和架构**:
```
┌─────────────────────────────────────────────────────────┐
│  平台          │  架构      │  文件格式                 │
├─────────────────────────────────────────────────────────┤
│  Windows       │  amd64     │  stock-monitor_*.zip      │
│  Windows       │  arm64     │  stock-monitor_*.zip      │
│  macOS         │  Universal │  stock-monitor_*.dmg      │
│  macOS         │  Universal │  stock-monitor_*.tar.gz   │
│  Linux         │  amd64     │  stock-monitor_*.tar.gz   │
│  Linux         │  arm64     │  stock-monitor_*.tar.gz   │
│  Debian/Ubuntu │  amd64     │  stock-monitor_*.deb      │
│  RHEL/Fedora   │  amd64     │  stock-monitor_*.rpm      │
└─────────────────────────────────────────────────────────┘
```

**GoReleaser 配置特性**:
- ✅ **Universal Binary** - macOS Intel + Apple Silicon 统一二进制
- ✅ **代码优化** - 使用 `-s -w` 标志减小二进制大小
- ✅ **版本注入** - 编译时注入版本、提交哈希、构建时间
- ✅ **Linux 包管理** - 自动生成 deb 和 rpm 包
- ✅ **校验和生成** - 自动生成 SHA256 校验和文件

**配置文件**: `.goreleaser.yaml`
```yaml
builds:
  - goos: [linux, darwin, windows]
    goarch: [amd64, arm64]
    ldflags:
      - -X main.version={{ .Version }}
      - -X main.commit={{ .ShortCommit }}
      - -X main.date={{ .Date }}

universal_binaries:
  - ids: [stock-monitor]
    replace: true  # macOS Universal Binary

archives:
  - formats: [tar.gz]
    format_overrides:
      - goos: windows
        formats: [zip]

nfpms:  # Linux packages
  - formats: [deb, rpm]
```

### 2. GitHub Actions CI/CD 流程 | GitHub Actions CI/CD Pipeline

**自动化工作流**:

```

    ├─ Job 1: goreleaser (Ubuntu)
    │   ├─ 编译所有平台二进制
    │   ├─ 创建 Universal Binary
    │   ├─ 打包为多种格式

    └─ Job 2: create-dmg (macOS)
```

### 核心配置详解 | Core Configuration Details

#### GoReleaser 配置 (.goreleaser.yaml)

**构建配置**:
```yaml
builds:
  - id: stock-monitor
    main: .
    binary: stock-monitor
    env:
      - CGO_ENABLED=0  # 禁用 CGO，确保跨平台兼容性
    goos: [linux, darwin, windows]
    goarch: [amd64, arm64]
    ldflags:
      - -s -w  # 移除符号表和调试信息，减小二进制大小
      - -X main.version={{ .Version }}
      - -X main.commit={{ .ShortCommit }}
      - -X main.date={{ .Date }}
```

**打包配置**:
```yaml
archives:
  - formats: [tar.gz]
    format_overrides:
      - goos: windows
        formats: [zip]  # Windows 使用 zip 格式
    files:
      - README*
      - LICENSE*
      - cmd/conf/config_demo.yaml
      - i18n/*.json
```

**Linux 包配置**:
```yaml
nfpms:
  - package_name: stock-monitor
    formats: [deb, rpm]
    bindir: /usr/bin
    contents:
      - src: ./cmd/conf/config.yaml
        dst: /etc/stock-monitor/config.yaml
        type: "config|noreplace"
      - src: ./i18n/*.json
        dst: /usr/share/stock-monitor/i18n/
```

#### GitHub Actions 工作流 (.github/workflows/release.yaml)

**触发条件**:
```yaml
on:
  push:
    tags:
      - 'v*'  # 推送 v* tag 时触发
```

**Job 1: GoReleaser**:
```yaml
jobs:
  goreleaser:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-go@v4
      - uses: goreleaser/goreleaser-action@v5
        with:
          version: latest
          args: release --clean
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
          HOMEBREW_TAP_GITHUB_TOKEN: ${{ secrets.HOMEBREW_TAP_GITHUB_TOKEN }}
```

**Job 2: Create DMG**:
```yaml
  create-dmg:
    runs-on: macos-latest
    needs: goreleaser
    steps:
      - uses: actions/download-artifact@v3
      - run: |
          npm install -g create-dmg
          create-dmg stock-monitor_*.tar.gz
      - uses: softprops/action-gh-release@v1
        with:
          files: stock-monitor_*.dmg
```

## 💡 架构决策与权衡 | Architecture Decisions & Tradeoffs

### 为什么使用 GoReleaser?

**优点** ✅:
- 支持多平台构建（Windows/macOS/Linux）
- 自动生成多种包格式（zip、tar.gz、deb、rpm、dmg）
- 与 GitHub Actions 无缝集成
- 自动生成 Release Notes 和校验和
- 支持 Homebrew Formula 自动更新

**缺点** ❌:
- 增加了一个外部依赖
- 需要学习 GoReleaser 配置

**决策**: GoReleaser 是业界标准，大幅简化发布流程，值得引入。

### 为什么分离 DMG 创建为单独 Job?

**原因**:
- DMG 创建需要 macOS 环境
- GoReleaser 在 Linux 上运行，无法直接创建 DMG
- 分离为单独 Job 可以并行执行，提高效率

**优点** ✅:
- 充分利用 GitHub Actions 的并行能力
- 清晰的职责分离
- 易于维护和调试

### 为什么 Homebrew 需要单独的 Token?

**原因**:
- Homebrew Formula 需要推送到 Homebrew Tap 仓库
- `GITHUB_TOKEN` 权限不足
- 需要 Personal Access Token 来更新 Formula

**安全考虑** ✅:
- Token 存储在 GitHub Secrets 中
- 仅在发布流程中使用
- 权限最小化（仅 repo 权限）
