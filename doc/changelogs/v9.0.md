## 🎯 版本概述 | Version Overview

v9.0 是一次重要的**功能增强**版本，为股票监控带来了全新的可视化体验和数据维度。核心亮点包括行内 Sparkline 走势迷你图、美股盘前盘后行情显示、A 股集合竞价/午休时段支持，以及多周期图表浏览能力。

**Major Points:**
- 📈 **Sparkline 走势迷你图** - 在表格中直接显示 Unicode 方块趋势图，一目了然

- 🍽️ **午休时段识别** - 新增 TradingStateLunchBreak，修复午休期间分时数据中断
- 📊 **分时成交量** - IntradayDataPoint 新增 Volume 字段，多 API 提取
- 📅 **多周期图表** - 支持 5D/1M/3M/1Y 多日图表浏览与降采样
- 🔗 **板块走势集成** - 板块成分股列表支持走势迷你图显示

## ✨ 主要特性 | Major Features

### 1. Sparkline 走势迷你图 | Sparkline Trend Mini-Charts

在持仓列表、自选列表和板块成分股中直接显示行内走势图，使用 Unicode 方块字符渲染：

```
▁▂▃▄▅▆▇█  —  8 级方块字符，精准映射价格区间
```

**特性**:
- 自动从分时数据加载最近交易日价格序列
- A 股采用红涨绿跌配色，美股/港股采用绿涨红跌配色
- 智能降采样 (Downsample)，适配列宽
- 无数据时显示灰色占位符
- 缓存机制与价格刷新频率对齐，避免重复 I/O

**新增文件**:
- `internal/ui/sparkline/sparkline.go` — 渲染引擎 (Generate/Downsample)
- `internal/intraday/loader.go` — 可复用数据加载器 (LoadLatestPrices/LoadMultiDay)

**配置启用**:
```yaml
# 在 portfolio_columns 或 watchlist_columns 中添加:
- trend          # 走势迷你图 | Trend Sparkline
```

---

### 2. 美股盘前盘后行情 | US Stock Pre/Post Market

StockData 新增 6 个字段，Yahoo Finance API 支持盘前盘后数据解析：

| 字段 | 说明 |
|------|------|
| `PreMarketPrice` | 盘前价格 |
| `PreMarketChange` | 盘前涨跌额 |
| `PreMarketPercent` | 盘前涨跌幅 |
| `PostMarketPrice` | 盘后价格 |
| `PostMarketChange` | 盘后涨跌额 |
| `PostMarketPercent` | 盘后涨跌幅 |

**配置启用**:
```yaml
# 在 portfolio_columns 或 watchlist_columns 中添加:
- pre_market     # 盘前价格 (美股) | Pre-Market Price (US)
- post_market    # 盘后价格 (美股) | Post-Market Price (US)
```

---

### 3. 分时数据增强 | Intraday Data Enhancement

**Volume 字段**: `IntradayDataPoint` 新增 `Volume` (int64) 字段，支持从 Sina、EastMoney、Tencent、Yahoo 四大 API 提取每分钟成交量。

**午休时段**: 新增 `TradingStateLunchBreak` (值 6)，准确识别 A 股 11:30-13:00 午休时段，修复了午休期间分时数据采集意外停止的问题。

**集合竞价**: 配置文件新增 A 股开盘竞价 (09:15-09:25) 和收盘竞价 (14:57-15:00) 时段定义。

---

### 4. 多周期图表 | Multi-Period Charts

支持在分时图表视图中浏览多个交易日的合并数据：

- **5D** — 最近 5 个交易日
- **1M** — 最近 1 个月
- **3M** — 最近 3 个月
- **1Y** — 最近 1 年

数据通过 `LoadMultiDay()` 加载，超过 300 个数据点时自动降采样以保证渲染性能。

---

### 5. 板块视图走势集成 | Sector View Sparkline Integration

板块成分股列表 (`RenderSectorStockList`) 通过闭包注入方式支持显示 Sparkline 走势图，进入板块成分股视图时自动触发分时数据采集。

### 架构设计决策

1. **闭包注入** — Sparkline 生成函数以闭包形式传入 Sector 视图，避免包间循环依赖
2. **轻量加载器** — `LoadLatestPrices()` 只解析价格数组，跳过完整 JSON 反序列化
3. **omitempty 兼容** — 所有新字段使用 `omitempty` JSON tag，旧数据文件完全兼容
4. **缓存对齐** — Sparkline 缓存 TTL 与 `config.Update.RefreshInterval` 对齐
