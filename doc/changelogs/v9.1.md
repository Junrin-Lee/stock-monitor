## 🔒 数据安全 | Data Safety

本版本最核心的改进，8 个 commit 全面加固数据持久化层的安全性。

### 1. 原子写入与持久化安全

**涉及文件**: `persistence.go`, `internal/data/persistence.go`, `internal/intraday/storage.go`

- **原子文件写入** — 所有持久化操作统一采用 temp + rename 模式，防止写入中断导致数据损坏
- **保存错误处理** — 写入失败时不再静默丢弃错误，确保上层感知写入状态
- **TOCTOU 竞态修复** — 修复分时数据存储中 check-then-act 竞态条件

### 2. 损坏检测与恢复

**涉及文件**: `internal/data/persistence.go`

- **损坏追踪** — 新增损坏计数器，在加载失败时阻止用默认值覆盖已有数据文件
- **自动备份** — 检测到损坏文件时自动备份原文件 (`.bak`)，再返回默认值
- **配置校验** — 加载配置时区分"文件不存在"和"读取错误"，避免误覆盖

### 3. 并发安全

**涉及文件**: `main.go`, `cache.go`, `handlers_search.go`, `internal/intraday/manager.go`, `internal/intraday/worker.go`

- **`atomic.Pointer[Model]`** — 全局 Model 改用原子指针，消除 data race（替代 mutex）
- **`stockPriceCache` 迭代锁** — 缓存遍历时加锁防止 concurrent map read/write
- **搜索 Worker 竞态修复** — 修复搜索视图分时数据 Worker 的数据竞争
- **Per-stock in-flight guard** — 使用 `sync.Map` 防止同一股票的并发抓取

### 4. 错误早返回

**涉及文件**: `internal/intraday/helpers.go`

- 文件读取或 JSON 反序列化失败时立即返回，不再继续处理可能损坏的数据

## 🌏 多市场与时区 | Multi-Market & Timezone

5 个 commit 增强多市场时区处理的正确性。

### 1. 时区感知告警频率

**涉及文件**: `alert_frequency.go`, `internal/alert/frequency.go`

- 告警频率的"同一天/同一周/同一月"判断现在使用**各市场本地时区**，而非系统时区

### 2. 时区感知 IsMarketOpen

**涉及文件**: `internal/intraday/trading.go`

### 4. API 路由修复

**涉及文件**: `internal/api/stock.go`

- 修复 A 股/港股代码意外 fall through 到美股 API 的问题

**涉及文件**: `internal/intraday/helpers.go`

- diff 算法增加成交量变化检测
- 移除未使用的冗余字段

## 🔧 技术实现 | Technical Implementation

### 文件变更统计

| 类别 | 文件数 | 变更行 |
|------|--------|--------|
| 数据层 (`internal/data/`, `persistence.go`) | 5 | +138 |
| 分时采集 (`internal/intraday/`) | 7 | +216 |

| 告警系统 (`alert_frequency.go`, `internal/alert/`) | 2 | +25 |
| API 层 (`internal/api/`) | 1 | +2 |
| UI/格式 (`format.go`, `handlers_*.go`) | 4 | +50 |
| 缓存 (`cache.go`, `internal/data/cache.go`) | 2 | +23 |
| 日志 (`internal/log/`) | 1 | +5 |
| 核心 (`main.go`, `types.go`, `intraday.go`) | 3 | +25 |

### 架构设计决策

1. **`atomic.Pointer[Model]`** — 选择 lock-free 原子指针替代 `sync.Mutex`，goroutine 读取全局 Model 无需获取锁，消除了最频繁的竞态路径
2. **Per-stock in-flight `sync.Map`** — 使用 `LoadOrStore` 原子操作实现幂等性，同一股票并发抓取请求自动去重
3. **损坏计数器模式** — 连续加载失败时递增损坏计数，拒绝用默认值覆盖可能有效的数据文件，优先保护用户数据
4. **节假日内存缓存** — 首次查询时加载日历并缓存，后续查询直接命中内存，避免重复网络调用
