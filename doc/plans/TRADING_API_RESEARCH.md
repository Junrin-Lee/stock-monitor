# 同花顺/券商交易接口调研报告

> **调研日期**: 2025-01-14
> **调研目标**: 接入同花顺账号同步自选股/持股，以及程序化控制买卖股票的可行性分析

---

## 一、调研概述

本调研围绕三个核心需求展开：
1. **自选股同步** - 从同花顺获取用户自选股列表
2. **持股同步** - 获取用户实际持仓信息
3. **交易控制** - 程序化下单买卖股票

---

## 二、同花顺官方接口方案

### 2.1 iFinD 数据接口

**官方网站**: https://quantapi.51ifind.com/

**功能概述**:
- 支持量化策略回测（历史数据）
- 实时行情监控（买卖点位）
- 个性化开发（定制报表）

**数据覆盖**:
- 股票、基金、债券、期货等金融市场
- 基本资料、财务报告、股本信息、估值指标
- 日频、分时、秒级高频数据

**支持开发语言**:
| 平台 | 语言支持 |
|------|----------|
| Windows | MATLAB, R, Python, VBA, C++, C#, Java |
| Linux | Python, C++, Java |

**申请方式**:
1. 访问 http://quantapi.10jqka.com.cn/ 下载免费版（需 iFinD 账号）
2. 通过同花顺私募之家申请试用
3. 客服热线: 952555

**⚠️ 重要限制**:
- **iFinD 是数据接口，不是交易接口**
- 无法获取用户自选股、持仓信息
- 无法执行买卖操作
- 主要面向机构用户，个人使用需评估成本

### 2.2 SuperMind 智能交易

**官方文档**: https://quant.10jqka.com.cn/view/help/22

SuperMind 是同花顺的量化交易平台，提供：
- 策略编写和回测
- 条件单设置
- 模拟交易

**限制**:
- 需要在同花顺平台内操作
- 非开放 API，无法外部集成

## 三、券商量化交易接口方案

### 3.1 QMT (迅投 QMT / MiniQMT)

**产品介绍**:
QMT 是迅投科技开发的量化交易系统，被多家券商采用。

**开通条件（一般要求）**:
| 类型 | 资金门槛 | 说明 |
|------|----------|------|
| 完整版 QMT | 50-100万 | 功能完整，支持高频 |
| MiniQMT | 1-10万 | 精简版，适合个人 |

**注意**: 具体门槛因券商而异，建议直接联系国投证券（原安信证券）客户经理确认。

**功能特点**:
- 合法合规的程序化交易
- 支持 Python 策略编写
- 可获取持仓、委托、成交信息
- 支持下单、撤单操作

### 3.2 PTrade (恒生电子)

**产品介绍**:
PTrade 是恒生电子开发的量化交易平台。

**开通条件**:
- 一般需要 100万+ 资金门槛
- 部分券商对活跃客户降低门槛

**功能特点**:
- 专业级量化交易平台
- 策略回测和实盘交易
- API 支持完善

### 3.3 国投证券（原安信证券）情况

**建议操作**:
1. 联系国投证券客户经理
2. 询问以下问题：
   - 是否支持 QMT/PTrade？
   - 个人投资者开通门槛是多少？
   - 是否有 MiniQMT 选项？
   - API 调用频率限制？

## 四、开源自动化方案

### 4.1 easytrader

**GitHub**: https://github.com/shidenggui/easytrader (9.2k ⭐)

**技术原理**:
- 基于 pywinauto 模拟键盘鼠标操作
- 通过 UI 自动化控制同花顺客户端
- OCR 识别验证码

**支持功能**:
- 同花顺客户端模拟操作
- MiniQMT 官方接口集成
- 雪球组合跟踪和再平衡
- JoinQuant/RiceQuant 模拟盘跟踪

**⚠️ 风险提示**:

| 风险类型 | 详细说明 |
|----------|----------|
| **法律风险** | 可能涉及知识产权侵犯、违反金融监管法规 |
| **账户风险** | 可能被券商封禁账户 |
| **资金风险** | UI 自动化操作错误可能导致资金损失 |
| **技术风险** | 界面更新可能导致脚本失效 |
| **稳定性** | 依赖硬编码控件ID，易因版本更新失效 |

### 4.2 jqktrader

**技术实现**:
- 基于 pywinauto 模拟操作
- 使用 Tesseract OCR 识别验证码
- 升级 easytrader 依赖兼容性

**当前状态**: ⚠️ **项目已停止维护**

**已知问题**:
- 验证码识别准确率不稳定
- 撤单功能与菜单变更不兼容
- 同花顺界面更新适配困难

## 五、网页爬虫方案

### 5.1 Cookie 获取自选股

**技术路线**:
1. 登录同花顺网页版获取 Cookie
2. 使用 Cookie 请求自选股 API
3. 解析返回的 JSON 数据

**技术挑战**:
- Cookie 中的 `hexin-v` 参数需要逆向 JS 生成逻辑
- 临时 Cookie 易失效，需要定期刷新
- 反爬机制较强

**参考资料**:
- [同花顺Cookie加密和Hook注入](https://blog.csdn.net/weixin_52392194/article/details/140604094)

### 5.2 合规性考量

- 遵守 robots.txt 规范
- 注意数据使用范围限制
- 避免高频请求

### 6.2 推荐方案

**理由**:
1. **合法合规** - 券商官方提供的接口
2. **功能完整** - 支持持仓查询、下单交易
3. **稳定可靠** - 不受客户端更新影响
4. **无封号风险** - 正规渠道使用

**下一步行动**:
1. 联系国投证券客户经理
2. 确认 QMT/MiniQMT 开通条件
3. 了解 API 文档和开发指南

#### 🥈 备选：手动导入 + 数据API

如果 QMT 门槛过高，可以：
1. 同花顺自选股导出为 txt/blk 文件
2. 开发导入功能到 stock-monitor
3. 使用现有免费 API 获取行情数据
