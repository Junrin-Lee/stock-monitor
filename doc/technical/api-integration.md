# API 集成与支持市场

支持的股票代码格式、数据源和容错机制。

## 股票代码格式

### A 股（上海和深圳）

| 市场 | 输入格式 | 示例 | 说明 |
|------|----------|------|------|
| **上交所** | `SH + 6位` 或 `6位` | `SH601138` / `601138` | 沪 = Shanghai |
| **深交所** | `SZ + 6位` 或 `6位` | `SZ000001` / `000001` | 深 = Shenzhen |

**A 股代码规则**：
- 上海以 `6` 开头（如 601138、600000）
- 深圳以 `0` 开头（如 000001、000725）
- 创业板以 `3` 开头（如 300001）

### 美股

| 市场 | 输入格式 | 示例 |
|------|----------|------|
| **纳斯达克/纽交所** | 大写字母代码 | `AAPL`, `MSFT`, `TSLA` |

**美股代码**：
- 通常 1-5 个大写字母
- 无需前缀

### 港股

| 市场 | 输入格式 | 示例 | 说明 |
|------|----------|------|------|
| **香港交易所** | `HK + 5位` 或 `标准格式` | `HK00700` / `0700.HK` | 腾讯 |

**港股代码规则**：
- 通常是 4-5 位数字
- 支持 `HKxxxx` 或 `xxxx.HK` 两种格式

## 数据源与 API

### A 股数据源

**实时行情** - 优先级排列：

```
腾讯 API (Primary)
  ↓ (失败)
新浪 API (Fallback)
  ↓ (失败)
显示 "-"  (显示不可用)
```

**特点**：
- 腾讯：速度快、数据准确
- 新浪：稳定、备份选项
- 自动重试：API 失败时自动尝试下一个

### 分时数据源

**优先级**：
```
新浪财经 (Primary - 分时走势)
  ↓
东方财富 (Fallback - 分时走势)
  ↓
跳过   (无法获取分时)
```

**说明**：
- 新浪：完整分时数据，更新频率高
- 东方财富：备份选项，覆盖较全

### 美股数据源

**实时行情** - 优先级排列：

```
Yahoo Finance
  ↓ (失败)
FMP API
  ↓ (失败)
TwelveData
  ↓ (失败)
显示 "-"
```

**特点**：
- Yahoo：覆盖面广、数据稳定
- FMP：数据质量高
- TwelveData：高频数据源

### 港股数据源

**实时行情** - 优先级排列：

```
Finnhub
  ↓ (失败)
东方财富
  ↓ (失败)
显示 "-"
```

**特点**：
- Finnhub：国际数据源
- 东方财富：本土数据源

### 股票搜索

**优先级**：
```
腾讯搜索 (A股)
  ↓
新浪搜索
  ↓
TwelveData (美股)
  ↓
未找到提示
```

## 容错机制

### 自动重试策略

```
调用 API
  ↓
成功? → 返回数据
  ↓ (失败)
记录错误
  ↓
切换到下一个数据源
  ↓
重试
  ↓
全部失败? → 显示 "-" 或缓存数据
```

### 错误处理

| 错误类型 | 处理方式 |
|----------|----------|
| 网络超时 | 自动重试下一个源 |
| API 限流 | 显示 "-"，稍后重试 |
| 代码无效 | 显示 "-" |
| 数据格式错误 | 使用缓存数据或显示 "-" |

### 缓存策略

- **缓存时间**：30 秒 TTL
- **缓存用途**：API 失败时显示最后有效数据
- **更新频率**：每 5 秒尝试更新（可配置）

## 代码转换

### 内部转换规则

系统内部会自动转换代码格式：

**用户输入** → **API 调用** → **存储**

示例：
```
用户输入：601138
  ↓
腾讯 API：601138.SS (上海)
新浪 API：sh601138
  ↓
存储：SH601138
```

### GBK 编码处理

中国 API (腾讯、新浪) 使用 GBK 编码：

```go
// 自动转换
GBK (来自 API) → UTF-8 (应用内) → GBK (发送请求)
```

用户无需关心，系统自动处理。

## API 限制

### 请求频率

| 数据源 | 限制 | 应对 |
|--------|------|------|
| 腾讯 | 较宽松 | 优先使用 |
| 新浪 | 中等 | 备用选项 |
| Finnhub | 严格 | 降低刷新频率 |
| Yahoo | 中等 | 缓存+重试 |

### 优化建议

1. **刷新间隔**：建议 5-10 秒
2. **降低频率**：网络不稳定时可设置 10-30 秒
3. **批量请求**：避免频繁单个请求

配置方式见：[配置说明](../guides/configuration.md)

## 多市场支持

### 自动识别

系统根据代码格式自动识别市场：

```
输入：SH601138 → A 股（上海）
输入：000001    → A 股（深圳）
输入：AAPL      → 美股
输入：0700.HK   → 港股
输入：HK00700   → 港股
```

### 时区处理

不同市场有不同交易时间：

| 市场 | 交易时间 (北京) | 时区 |
|------|-------------------|------|
| A 股 | 09:30-15:00 | UTC+8 |
| 港股 | 09:30-16:00 | UTC+8 |
| 美股 | 21:30-04:00 | UTC-5 |

系统自动处理时区转换，用户看到的都是北京时间。

## 常见问题

**Q: 为什么某只股票显示 "-"？**

A: 可能是以下原因：
1. 网络连接问题
2. 股票代码格式不正确
3. 所有 API 都失败
4. 非交易时间

**Q: 美股实时数据准确吗？**

A: 美股数据来自多个高质量数据源，数据准确。但美股交易时间是北京时间晚 21:30-04:00。

**Q: 为什么自选列表中美股没有换手率？**

A: 换手率数据仅对 A 股和港股可用，美股的数据源不提供此指标。

**Q: 可以自定义数据源吗？**

A: 目前版本不支持。建议在 GitHub 上提交 Feature Request。
