## 概述

### 核心能力

Stock Monitor 的告警系统提供：

| 功能 | 说明 |
|------|------|
| **实时监控** | 后台 5 秒检查一次，支持数千个告警同时运行 |
| **多类型告警** | 价格、涨跌幅、成交量（A股专属）三种类型 |
| **智能频率** | 一次性、每日、每周、每月、自定义间隔五种模式 |
| **跨平台通知** | macOS/Linux/Windows 原生通知支持 |
| **批量管理** | 按标签或市场快速为多只股票配置告警 |
| **灵活配置** | 支持编辑已有告警，修改条件和频率无需重建 |

### 工作原理

```
┌─────────────┐
│  后台监控   │  每 5 秒检查一次所有告警条件
└─────┬───────┘
      │
      ├─► 检查: 当前价格 > 目标价? ✓
      │
      ├─► 检查: 是否已在今天触发? (频率边界)
      │
      ├─► 触发条件满足
      │
      └─► 推送系统通知 + 更新告警状态
```

## 告警类型

### 1. 价格告警

**适用市场**：A 股、美股、港股
**说明**：监控股价是否突破关键价格位
**常见条件**：高于、低于、等于

#### 典型应用

| 场景 | 配置 | 效果 |
|------|------|------|
| **止损保护** | 低于 120 元 | 股价跌至止损点立即通知 |
| **目标价提醒** | 高于 150 元 | 达到预期目标价时提醒 |
| **关键支撑** | 低于 100 元 | 突破支撑位风险预警 |

**配置示例**：
```
告警类型: 价格告警
股票: SH601138 (工业富联)
条件: 低于 60.00 元  ← 设定止损价
频率: 每日  ← 每天检查
```

### 2. 涨跌幅告警

**适用市场**：A 股、美股、港股
**说明**：监控日涨跌幅是否达到阈值
**常见条件**：高于、低于

#### 典型应用

| 场景 | 配置 | 效果 |
|------|------|------|
| **强势机会** | 高于 +5% | 发现日内强势股 |
| **风险预警** | 低于 -3% | 跌幅过大及时止损 |
| **板块爆发** | 高于 +3% | 发现板块行情 |

**配置示例**：
```
告警类型: 涨跌幅告警
股票: SZ000725 (京东方A)
条件: 高于 +3%  ← 日涨幅超过 3%
频率: 一次性  ← 条件满足一次就停用
```

### 3. 成交量告警

**适用市场**：A 股仅有
**说明**：监控成交量是否异常
**常见条件**：高于、低于日均值的倍数

#### 典型应用

| 场景 | 配置 | 效果 |
|------|------|------|
| **放量突破** | 高于日均 150% | 异常放量发现买点 |
| **萎靡跌停** | 低于日均 50% | 成交量萎靡预示见底 |
| **财报日异动** | 高于日均 200% | 财报日异常成交量 |

**配置示例**：
```
告警类型: 成交量告警
股票: SH600000 (浦发银行)
条件: 高于日均 150%  ← 异常放量
频率: 每日  ← 每日开盘后检查
```

## 触发频率

### 5 种频率模式详解

| 模式 | 触发规则 | 使用场景 | 适用类型 |
|------|---------|--------|---------|
| **一次性** | 条件满足立即触发，之后自动禁用 | 临时监控，只想被通知一次 | 所有类型 |
| **每日** | 每天固定检查，今日仅触发一次 | 日内追踪关键价位 | 所有类型 |
| **每周** | 每周指定日期检查一次 | 周度计划，定期评估 | 所有类型 |
| **每月** | 每月指定日期检查一次 | 月度统计，长期追踪 | 所有类型 |
| **自定义** | 每 N 天检查一次（N 由用户指定） | 灵活周期，自由定制 | 所有类型 |

### 时间边界说明

**日边界**
- 以市场交易日计算，非自然日期
- 触发后同日不再重复触发

**周边界**
- 周一 ~ 周日（7 天）
- 触发后周内不再重复

**月边界**
- 自然月份（1 月 ~ 12 月）
- 月末自动重置，下月可再次触发

**示例**：
```
添加时间: 12 月 31 日
频率: 每日
检查时间: 每天 15:00 后

12 月 31 日：检查并触发 ✓
1 月 1 日：重新计时，可再次触发 ✓
```

## 快速上手

### 添加单个告警（5 步流程）

#### 步骤 1：进入告警管理

在持股/自选列表中：
- 按 `Alt+A`，或
- 按 `E` 编辑列表后选择"告警管理"

#### 步骤 2：选择添加方式

```
告警管理菜单:
├─ [A] 添加单个告警 ← 推荐（适合关键股票）
├─ [B] 批量添加告警 ← 高效（适合多只股票）
├─ [E] 编辑告警
├─ [D] 删除告警
└─ [Space] 启用/禁用
```

#### 步骤 3：选择告警类型

```
选择告警类型:
├─ 价格告警
├─ 涨跌幅告警
└─ 成交量告警 (仅 A 股)
```

#### 步骤 4：设置触发条件

```
配置条件:
├─ 条件类型: [ 高于 ] [ 低于 ] [ 等于 ]
├─ 阈值: _______  ← 输入数值
└─ 预览: "当价格高于 120.00 元时触发"
```

#### 步骤 5：选择触发频率

```
选择频率:
├─ 一次性     ← 触发一次后自动禁用
├─ 每日       ← 每天检查
├─ 每周       ← 每周检查
├─ 每月       ← 每月检查
└─ 自定义     ← 每 N 天检查
```

完成后告警生效！

## 批量操作

### 按标签批量添加

**场景**：为"科技"板块的所有股票统一设置告警

**步骤**：

1. 进入告警管理 → 选择"批量添加"
2. 选择"按标签" → 选择目标标签（如"科技"）
3. 配置告警条件和频率
4. 确认执行

**优势**：
- 一次操作监控整个板块
- 避免逐个配置的繁琐
- 新增同标签股票自动继承配置（可选）

**示例**：
```
标签: 科技 (包含 AAPL, MSFT, GOOGL, TSLA)
条件: 涨跌幅 > +3%
频率: 一次性

→ 任何科技股当日涨幅突破 3% 时收到通知
```

### 按市场批量添加

**场景**：为所有美股持仓设置开盘价监控

**步骤**：

1. 进入告警管理 → 选择"批量添加"
2. 选择"按市场" → 选择目标市场（美股/A股/港股）
3. 配置统一告警
4. 确认执行

**优势**：
- 市场级别统一管理
- 快速覆盖大规模持仓
- 市场特定策略一键配置

**示例**：
```
市场: 美股 (包含所有持仓美股)
条件: 价格 > 120% 昨收  ← 高开机会
频率: 每日

→ 美股开盘后检查是否有高开机会
```

## 通知系统

### 跨平台原生通知

#### macOS

**通知方式**：系统通知中心
**特点**：右上角通知气泡 + 声音

```
┌─────────────────────────┐
│  📈 Stock Monitor       │
│  工业富联 (SH601138)    │
│  价格突破目标位         │
│  当前: ¥62.50 | 目标: ¥62.00 │
└─────────────────────────┘
```

#### Linux

**通知方式**：D-Bus 通知（Freedesktop 标准）
**特点**：与桌面环境集成

```
┌─────────────────────────┐
│  📈 Stock Monitor       │
│  京东方A (SZ000725)     │
│  涨幅超过 +3%           │
└─────────────────────────┘
```

#### Windows

**通知方式**：Toast 通知
**特点**：右下角弹窗 + 声音

```
右下角弹窗:
┌─────────────────────────┐
│  📈 Stock Monitor       │
│  浦发银行 (SH600000)    │
│  成交量异常放量         │
│  [打开] [关闭]          │
└─────────────────────────┘
```

### 通知内容

**标题**：`📈 股票告警 - [代码] ([名称])`

**正文**：
- 告警类型和条件
- 当前数值 | 目标数值
- 触发时间

**示例**：
```
标题: 📈 股票告警 - SH601138 (工业富联)
正文:
  价格突破目标位
  当前: ¥62.50 | 目标: ¥62.00
  时间: 2026-01-19 14:35:22
```

## 管理技巧

### 1. 分层告警策略

设置多层告警，避免单一维度监控不足：

```
第 1 层：防线告警（一次性）
  ├─ 止损价：买入价 -5% → 保护本金
  └─ 风险提示：当月跌幅 -10% → 危险信号

第 2 层：日度告警（每日）
  ├─ 目标价：买入价 +10% → 日内利好确认
  └─ 开盘波动：涨幅 >3% → 日内机会

第 3 层：周度告警（每周）
  ├─ 周线目标 → 周度追踪
  └─ 相对表现 → 和行业比较

第 4 层：月度告警（每月）
  └─ 月度目标价 → 长期跟踪
```

### 2. 避免告警疲劳

告警过多会导致"狼来了"效应：

```
❌ 不佳实践：
  - 为所有 100 只自选股票都添加告警
  - 为同一股票添加多个相似条件的告警
  - 使用过于敏感的告警阈值（如 ±0.5%）

✅ 最佳实践：
  - 只为关键股票添加告警（20 只以内重点监控）
  - 为不同目标添加告警（止损、目标价、异常波动）
  - 使用合理的阈值（止损 ±3-5%、目标价 ±10%）
```

### 3. 定期审查

```
建议周期：
├─ 每周：删除已实现目标的告警
├─ 每月：评估告警触发情况，调整灵敏度
└─ 每季度：复盘告警策略，优化配置
```

### 4. 编辑已有告警

**v7.1+ 新功能**：可在编辑告警时修改触发频率

按 `E` 编辑告警，可修改：
- 告警条件（价格、涨跌幅、成交量）
- 触发频率（一次性 ↔ 日/周/月/自定义）
- 启用/禁用状态

## 最佳实践

### 场景 1：监控持仓止损

```
目标: 保护持仓本金
配置:
  ├─ 告警类型: 价格告警
  ├─ 条件: 低于 成本价 -5%  ← 止损点
  ├─ 频率: 每日
  └─ 触发: 每天交易开始后检查

效果: 股价跌至止损点时收到通知，及时做出反应
```

### 场景 2：关注热点板块

```
目标: 发现板块爆发机会
配置:
  ├─ 告警类型: 涨跌幅告警
  ├─ 条件: 高于 +5%  ← 强势涨幅
  ├─ 频率: 一次性
  ├─ 应用于: "科技" 标签下所有股票
  └─ 触发: 首次达到就通知

效果: 发现行业爆发机会，及时介入
```

### 场景 3：追踪美股财报日

```
目标: 财报日前后成交量异常监控
配置:
  ├─ 告警类型: 成交量告警 (仅 A 股)
  ├─ 条件: 高于日均 150%
  ├─ 频率: 每周  ← 定期检查
  └─ 触发: 每周一 10:00 检查

效果: 财报日前后成交量异常时收到提醒
```

### 场景 4：市场特定策略

**A 股策略**：
```
特点: 涨停板容易一次性突破，需要快速反应
建议:
  ├─ 使用"一次性"频率捕捉涨停机会
  ├─ 配置成交量告警监控异常放量
  └─ 在 09:30-15:00 交易时间段内设置告警
```

**美股策略**：
```
特点: 盘中波动相对平稳，财报日波动大
建议:
  ├─ 使用"每日"频率日常监控
  ├─ 财报日前提前设置关键价位告警
  └─ 避免北京时间白天频繁通知（美股晚盘交易）
```

**港股策略**：
```
特点: 中资股表现集中，时差管理需注意
建议:
  ├─ 为中资股添加标签，单独监控
  ├─ 换手率可参考，配合价格告警
  └─ 09:30-16:00 是港股交易时间
```

## 性能与限制

### 性能指标

| 指标 | 值 | 说明 |
|------|-----|------|
| 告警检查周期 | 5 秒 | 后台持续监控 |
| 单个告警检查时间 | <1ms | O(1) 复杂度 |
| 1000 个告警检查耗时 | ~15ms | 极高效率 |
| CPU 占用 | <1% | 后台占用极低 |
| 内存占用 | ~5-10MB | 告警数据存储很小 |

### 建议使用

✅ **支持场景**：
- 数百到数千个告警同时运行
- 为所有持仓和自选股票配置告警
- 多层次的告警策略

❌ **不建议**：
- 超过 10,000 个告警（内存和磁盘考虑）

## 常见问题

### Q: 告警添加后如何编辑？

A: 在告警列表中按 `E` 键编辑。v7.1+ 支持修改触发频率，无需重新添加。

### Q: 一个股票能添加多个告警吗？

A: 可以！建议为同一股票设置多个不同条件的告警（如止损价 + 目标价）。

### Q: 告警如何禁用而不删除？

A: 在告警列表中按 `Space` 键切换启用/禁用状态。禁用后可随时重新启用。

### Q: 哪里能找到告警历史记录？

A: 告警历史存储在 `data/alert_data.json` 文件中，包含所有告警触发记录。

### Q: 成交量告警为什么只支持 A 股？

A: 因为美股和港股的成交量单位不同，难以统一计算日均值。

### Q: 能否设置告警的静默时间？

A: 目前版本暂不支持。建议通过告警频率（一次性、每日等）控制通知频率。

### Q: 多个告警同时触发会怎样？

A: 每个告警独立触发独立通知，几乎同时发送多个通知。

### Q: 告警条件能否支持区间（如 100-120 元）？

A: 目前支持单向条件（高于、低于、等于）。区间可通过两个告警实现（高于 100 + 低于 120）。
