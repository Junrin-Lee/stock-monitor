## 日内交易者

**投资风格**：专注盘中波动，追求短期收益

### 推荐配置

```yaml
update:
  refresh_interval: 2              # 2 秒刷新一次
  auto_update: true

display:
  max_lines: 15                    # 显示更多行便于扫描
  decimal_places: 2

portfolio_columns:
  - cursor
  - code
  - name
  - price
  - today_change
  - position_profit
```

### 核心工作流

| 时间 | 操作 | 说明 |
|------|------|------|
| **09:30** | 进入监控 | 查看开盘表现 |
| **09:35-11:30** | 按涨幅排序 | 找强势股，按 S 键排序 |
| **添加告警** | 为热点股添加一次性告警 | 价格或涨幅告警 |
| **查看图表** | 按 V 查看分时图 | 确认支撑阻力 |
| **快速操作** | 编辑持仓 | 利用 E 键快速修改成本 |

### 快速检查清单

- [ ] 刷新间隔设置为 2-3 秒
- [ ] 表格显示关键列：代码、现价、今日涨幅、盈亏
- [ ] 熟练使用快捷键：`S`(排序)、`V`(图表)、`A`(添加)、`E`(编辑)
- [ ] 为关键价位设置一次性告警
- [ ] 定期查看分时图确认趋势

## 价值投资者

**投资风格**：基于基本面分析，追求长期增长

### 推荐配置

```yaml
update:
  refresh_interval: 10             # 10 秒更新一次
  auto_update: true

display:
  max_lines: 20                    # 显示更多数据
  decimal_places: 3

portfolio_columns:
  - cursor
  - code
  - name
  - price
  - cost
  - quantity
  - today_change
  - position_profit
  - profit_rate
```

### 核心工作流

| 周期 | 操作 | 说明 |
|------|------|------|
| **周一** | 建立自选列表 | 添加 5-10 个投资目标 |
| **周一-周五** | 监控价格 | 为每只股票设置日度告警 |
| **周末** | 复盘分析 | 按 S 排序查看周度表现 |
| **每月** | 调整持仓 | 评估是否达到买入价 |

### 组合构建

```
自选列表组织:
├─ 潜在目标 (标签: potential)
│  └─ 10 只感兴趣的股票
├─ 观察池 (标签: watching)
│  └─ 等待买入价的股票
└─ 持仓 (标签: holding)
   └─ 已买入的股票

告警策略:
├─ 第 1 层：目标价告警 (每日)
└─ 第 2 层：周度评估 (每周)
```

### 快速检查清单

- [ ] 为自选列表中的股票添加标签
- [ ] 设置每日告警监控目标价
- [ ] 按盈亏率排序评估表现
- [ ] 月度复盘，调整持仓权重

## 板块研究员

**投资风格**：专注行业轮动，把握板块机会

### 推荐配置

```yaml
display:
  max_lines: 25                    # 显示更多行便于对比

watchlist_columns:
  - cursor
  - tag
  - code
  - name
  - price
  - today_change
  - volume
```

### 核心工作流

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| **添加板块** | `T` 添加标签 | 为股票分类：科技、医药、新能源等 |
| **查看板块** | `G` 分组查看 | 按板块分别查看 |
| **对比分析** | `S` 排序 | 按涨幅对比各板块表现 |
| **批量告警** | `B` 批量添加 | 为整个板块添加告警 |

### 板块监控策略

```
场景: 新能源板块爆发

第 1 步：识别板块
  └─ 自选列表中添加所有新能源股票

第 2 步：标签分类
  └─ 为所有股票添加"新能源"标签

第 3 步：批量告警
  └─ 为"新能源"标签下所有股票添加
     涨幅告警 (高于 +3%)，频率: 一次性

第 4 步：监控触发
  └─ 等待告警通知

第 5 步：深入分析
  └─ 收到告警 → 按 V 查看分时图
    → 按 S 排序对比其他股票
    → 决定是否介入
```

### 快速检查清单

- [ ] 按行业创建合理的标签体系
- [ ] 使用标签分组快速查看板块
- [ ] 为重点板块设置批量告警
- [ ] 利用排序功能对比板块表现

## 美股/港股投资者

**投资风格**：跨市场配置，多币种管理

### 推荐配置

```yaml
system:
  language: zh

update:
  refresh_interval: 5

# 支持代码格式
# A 股: SH601138, 000001
# 美股: AAPL, MSFT
# 港股: HK00700, 0700.HK
```

### 市场交易时间

| 市场 | 交易时间(北京) | 数据质量 | 建议操作时段 |
|------|----------------|---------|------------|
| **A 股** | 09:30-15:00 | 实时数据 | 日间 09:30-15:00 |
| **港股** | 09:30-16:00 | 实时数据 | 日间 09:30-16:00 |
| **美股** | 21:30-04:00 | 实时数据 | 晚间 21:30-04:00 |
| **非交易时** | 其他时间 | 昨日收盘 | 只显示昨收价 |

### 工作流

**日间** (09:30-15:00)：
```
1. 监控 A 股和港股
2. 为美股设置日度告警
3. 关注美股财报日
```

**晚间** (21:30-04:00)：
```
1. 实时观看美股走势
2. 调整次日策略
3. 查看美股分时图
```

### 市场特定策略

**A 股特点**：
- 容易涨停（一次性突破）→ 使用"一次性"频率
- 成交量重要 → 配置成交量告警
- 交易时间：09:30-15:00

**美股特点**：
- 波动相对平稳 → 使用"每日"频率
- 财报日易波动 → 提前设置关键价位
- 交易时间：北京晚 21:30-04:00

**港股特点**：
- 中资股集中 → 用标签单独监控
- 换手率有参考 → 配合价格告警
- 交易时间：09:30-16:00

## 最佳实践

### 1. 告警策略设计

**分层告警框架**：
```
防线 1：止损告警（一次性）
  └─ 价格低于成本 -5%，触发一次就禁用

防线 2：日度告警（每日）
  └─ 价格高于成本 +10%，每天检查

防线 3：周度告警（每周）
  └─ 评估周度表现，每周一检查

防线 4：月度告警（每月）
  └─ 评估月度目标，月初检查
```

### 2. 标签体系设计

**推荐分类**：
```
行业类：科技、医药、金融、消费、能源
概念类：新能源、人工智能、芯片、云计算
风险类：高风险、中风险、低风险、保守
阶段类：建仓、持仓、减仓、观察
```

### 3. 排序技巧

```
快速发现:
- 涨幅排序: 找强势股
- 成交量排序: 找活跃股
- 盈亏率排序: 评估表现

定期分析:
- 按代码排序: 便于查找
- 按价格排序: 查看价格分布
- 按持股数排序: 评估头寸规模
```

### 4. 配置优化

```
根据场景调整:
- 日内交易: 刷新 2-3 秒，显示关键列
- 长期持仓: 刷新 10+ 秒，显示详细信息
- 板块研究: 显示更多行便于对比

根据网络调整:
- 快速网络: 刷新 2-3 秒
- 普通网络: 刷新 5-7 秒
- 慢速网络: 刷新 10+ 秒
```

### 5. 数据管理

**定期备份**：
```bash
# 每周备份
cp -r data/ backup_$(date +%Y%m%d)/
```

**定期清理**：
```
- 每月：删除已实现目标的告警
- 每季度：复盘整个组合
- 每半年：整理标签体系
```
