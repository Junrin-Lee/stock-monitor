## 系统要求

### 最低配置

| 项目 | 要求 |
|------|------|
| **Go 版本** | 1.25.0 或更高版本 |
| **操作系统** | Windows、macOS 或 Linux |
| **终端** | 支持 ANSI 颜色（推荐） |
| **网络** | 需要网络连接以获取实时数据 |

### 版本检查

检查你的 Go 版本：

```bash
go version
```

如果版本不符，请访问 [golang.org](https://golang.org/dl) 下载新版本。

## 安装步骤

### 1. 克隆项目

```bash
git clone <repository-url>
cd stock-monitor
```

### 2. 安装依赖

```bash
go mod download
```

### 3. 编译程序

标准编译：
```bash
go build -o cmd/stock-monitor
```

**带 race 检测的编译**（用于调试并发问题）：
```bash
go build -race -o cmd/stock-monitor
```

### 4. 运行程序

```bash
./cmd/stock-monitor
```

首次运行时程序会自动创建配置文件和数据目录：
- `cmd/conf/config.yml` - 配置文件
- `data/` - 数据目录

## 首次运行

### 启动流程

程序启动时有两种情况：

**情况 1：无持仓数据（首次运行）**
```
┌─────────────────────────────────┐
│    Stock Monitor - 欢迎          │
├─────────────────────────────────┤
│  主菜单:                        │
│  1. 持股列表                    │
│  2. 自选列表                    │
│  3. 设置                        │
│  4. 退出                        │
└─────────────────────────────────┘
```

**情况 2：有持仓数据**
```
程序直接进入实时监控模式（持股列表）
```

### 改变行为

修改 `cmd/conf/config.yml` 中的 `system.auto_start` 配置：

```yaml
system:
  auto_start: false  # false = 显示菜单，true = 自动进入监控
```

## 基础操作

### 添加第一只股票

**方式 1：通过持股列表添加**

1. 选择"持股列表"（或直接启动）
2. 按 `A` 键或在菜单选择"添加"
3. 输入股票代码（例如：`SH601138` 或 `AAPL`）
4. 输入成本价和持股数量
5. 确认添加

**支持的代码格式：**

| 市场 | 格式示例 | 说明 |
|------|----------|------|
| 上海 A 股 | `SH601138` 或 `601138` | 6 位数字 |
| 深圳 A 股 | `SZ000001` 或 `000001` | 6 位数字 |
| 美股 | `AAPL` 或 `TSLA` | 大写字母代码 |
| 港股 | `HK00700` 或 `0700.HK` | 4-5 位数字 |

### 基本界面导航

| 按键 | 功能 |
|------|------|
| `↑` `↓` / `W` `S` | 上下导航 |
| `Enter` 或 `Space` | 确认选择 |
| `ESC` 或 `Q` | 返回上级 |
| `Ctrl+C` | 退出程序 |

### 查看股票信息

添加成功后，你会看到一张表格显示：

```
┌──────────┬──────────┬────────┬────────┬─────────┐
│   代码   │   名称   │  现价  │今日涨幅│ 盈亏率  │
├──────────┼──────────┼────────┼────────┼─────────┤
│ SH601138 │ 工业富联 │  61.63 │ -2.91% │ +18.6%  │
└──────────┴──────────┴────────┴────────┴─────────┘
```

- **现价**：实时股价（每 5 秒刷新）
- **今日涨幅**：当日涨跌百分比
- **盈亏率**：持仓总盈亏百分比

### 常见问题

**Q：股票数据显示 "-" 是什么原因？**

A：可能是以下原因之一：
- 网络连接问题 - 检查网络
- 股票代码错误 - 确认代码格式正确
- API 临时故障 - 等待几秒后重试

**Q：能否同时监控 A 股、美股、港股？**

A：可以！系统支持多市场混合监控，会自动识别和处理不同市场的股票。

**Q：首次运行为什么很慢？**

A：首次运行需要：
1. 创建配置文件
2. 创建数据目录
3. 获取初始股票数据

这通常只需要 5-10 秒。之后的启动会快得多。
