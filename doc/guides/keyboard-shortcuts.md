## 通用快捷键

| 按键 | 功能 | 说明 |
|------|------|------|
| `↑` / `W` / `K` | 上导航 | 移到上一项 |
| `↓` / `S` / `J` | 下导航 | 移到下一项 |
| `←` / `A` | 左导航 | 某些菜单中返回 |
| `→` / `D` | 右导航 | 某些菜单中前进 |
| `Enter` / `Space` | 确认选择 | 执行选中项 |
| `ESC` / `Q` | 返回上级 | 返回前一个菜单 |
| `Ctrl+C` | 强制退出 | 立即退出程序 |
| `Ctrl+D` | 显示调试信息 | 在监控界面显示日志 |

## 持股列表专用

### 导航与查看

| 按键 | 功能 |
|------|------|
| `↑` `↓` | 上下选择股票 |
| `Home` | 回到列表顶部 |
| `End` | 跳到列表底部 |
| `Page Up` | 上一页 |
| `Page Down` | 下一页 |
| `V` | **查看分时图表** - 按 V 后显示选中股票的分时走势图 |

### 操作

| 按键 | 功能 | 流程 |
|------|------|------|
| `A` | **添加新股票** | A → 输入代码 → 成本价 → 持股数 → 确认 |
| `E` | **编辑股票信息** | E → 修改数据 → 确认 |
| `D` | **删除股票** | D → 确认删除 |
| `S` | **排序设置** | S → 选择字段 → Enter 切换升降序 |
| `C` | **清除排序** | 在排序菜单中按 C 恢复默认顺序 |

### 可排序字段（11 个）

| 序号 | 字段 | 说明 |
|------|------|------|
| 1 | 代码 | 股票代码 |
| 2 | 名称 | 股票名称 |
| 3 | 现价 | 实时股价 |
| 4 | 成本价 | 买入成本 |
| 5 | 持股数 | 持仓数量 |
| 6 | 今日涨幅 | 当日涨跌百分比 |
| 7 | 持仓盈亏 | 盈亏金额 |
| 8 | 盈亏率 | 盈亏百分比 |
| 9 | 市值 | 当前市值 |
| 10 | 开盘价 | 今日开盘价 |
| 11 | 最高/最低 | 今日最高最低价 |

## 自选列表专用

### 导航与查看

| 按键 | 功能 |
|------|------|
| `↑` `↓` | 上下选择股票 |
| `V` | **查看分时图表** |
| `C` | **清除标签筛选** - 显示全部股票 |
| `G` | **分组查看** - 按标签分组显示 |

### 操作

| 按键 | 功能 | 流程 |
|------|------|------|
| `A` | **添加到自选** | A → 输入代码 → 确认 |
| `D` | **删除自选** | D → 确认删除 |
| `T` | **标签管理** | T → [A]添加 / [D]删除 / [E]编辑 |
| `S` | **排序设置** | S → 选择字段 → Enter 切换升降序 |

### 可排序字段（7 个）

| 序号 | 字段 | 说明 |
|------|------|------|
| 1 | 标签 | 股票标签 |
| 2 | 代码 | 股票代码 |
| 3 | 名称 | 股票名称 |
| 4 | 现价 | 实时股价 |
| 5 | 今日涨幅 | 当日涨跌百分比 |
| 6 | 成交量 | 成交量 |
| 7 | 换手率 | 换手率百分比 |

## 排序菜单

| 按键 | 功能 |
|------|------|
| `↑` `↓` | 选择排序字段 |
| `Enter` | 应用排序 / 切换升降序 |
| `C` | **清除排序** - 恢复默认顺序 |
| `ESC` | 返回列表 |

### 排序示例

**按盈亏率排序（高到低）**：
```
1. 按 S 进入排序菜单
2. 选择"盈亏率"字段
3. 按 Enter 应用排序（升序）
4. 再按 Enter 切换为降序
5. 按 ESC 返回
```

## 告警列表专用快捷键

### 导航与查看

| 按键 | 功能 |
|------|------|
| `↑` `↓` | 上下选择告警 |
| `Space` | **启用/禁用** 选中告警 |

### 操作

| 按键 | 功能 | 流程 |
|------|------|------|
| `A` | **添加单个告警** | A → 选择股票 → 类型 → 条件 → 频率 → 确认 |
| `B` | **批量添加** | B → 按标签/按市场 → 条件 → 频率 → 确认 |
| `E` | **编辑告警** | E → 修改条件或频率 → 确认 |
| `D` | **删除告警** | D → 确认删除 |

### 告警操作流程图

```
┌─────────────────────────────────────────┐
│          告警管理界面                    │
├─────────────────────────────────────────┤
│  [↑↓] 选择告警                          │
│  [A] 添加单个                           │
│  [B] 批量添加                           │
│  [E] 编辑                               │
│  [D] 删除                               │
│  [Space] 启用/禁用                      │
└─────────────────────────────────────────┘
     ↓ 按 E 编辑 ↓
┌─────────────────────────────────────────┐
│  编辑告警（v7.1+ 新功能）                │
├─────────────────────────────────────────┤
│  修改内容:                              │
│  - 告警条件 (新价格、新阈值等)          │
│  - 触发频率 (一次 ↔ 日/周/月)          │
│  - 启用/禁用状态                        │
└─────────────────────────────────────────┘
```

## 快速参考卡

### 日常最常用 (TOP 5)

```
场景: 快速监控和管理持股

1. 查看分时图表: 按 V
2. 排序找热点: 按 S → 选字段 → Enter
3. 添加自选: 按 A → 输入代码
4. 管理告警: 进入告警 → 按 A/E/D
5. 退出: 按 ESC 返回上级 / Ctrl+C 退出
```

### 完整快捷键速记

**持股列表模式**：
```
操作: A(加) E(编) D(删) S(排) V(图)
导航: ↑↓(移) ESC(返) Ctrl+C(退)
```

**自选列表模式**：
```
操作: A(加) D(删) T(标) S(排) V(图)
导航: ↑↓(移) C(清筛) G(分组)
```

**告警管理模式**：
```
操作: A(单加) B(批加) E(编) D(删)
状态: Space(启/禁) ↑↓(选)
```
