## 📱 告警系统快速上手 (v6.0新特性)

### 添加单个告警（5步流程）

1. **进入告警管理**: 在持股/自选列表中按 `Alt+A` 或从菜单选择"告警管理"
2. **选择告警类型**:
   - **价格告警** - 当股价达到特定价格时触发
   - **涨跌幅告警** - 当涨跌幅达到特定百分比时触发
   - **成交量告警** - 当成交量达到特定值时触发（仅A股）
3. **设置触发条件**:
   - 选择条件类型（高于/低于/等于）
   - 输入阈值（价格或百分比）
4. **选择触发频率**（5种模式任选）:
   - **一次性** - 条件满足后触发一次，自动禁用告警
   - **每日** - 每天固定时间检查，符合条件则触发（仅触发一次/天）
   - **每周** - 每周指定日期检查一次
   - **每月** - 每月指定日期检查一次
   - **自定义** - 每N天检查一次（N由用户指定）
5. **启用告警** - 告警生效，系统每5秒检查一次是否满足条件

### 批量添加告警（4步流程）

**方式1：按标签批量**
1. 进入告警管理 → 选择"批量添加"
2. 选择目标标签（如"科技"、"医药"）
3. 配置告警条件和频率（应用于所有该标签股票）
4. 确认执行 → 一键为所有相关股票添加告警

**方式2：按市场批量**
1. 进入告警管理 → 选择"批量添加"
2. 选择目标市场（A股/美股/港股）
3. 配置告警条件和频率
4. 确认执行 → 自动为所有选中市场的股票添加告警

### 典型使用场景（3个示例）

**场景1：监控持仓止损**
```
- 告警类型：价格告警
- 条件：低于 120 元（设定止损价）
- 频率：每日（每天交易开始时检查）
→ 股价跌至止损点时收到通知，及时做出反应
```

**场景2：关注热点板块**
```
- 告警类型：涨跌幅告警
- 条件：高于 +5%（设定强势涨幅）
- 频率：一次性（首次达到就触发）
→ 发现行业爆发机会，及时介入
```

**场景3：追踪美股财报日**
```
- 告警类型：成交量告警（若可用）
- 条件：高于日均成交量 150%
- 频率：每周（每周一检查一次）
→ 财报日前后成交量异常时收到提醒
```

### 告警通知方式

系统支持**跨平台原生通知**：

| 系统 | 通知方式 | 效果 |
|------|---------|------|
| **macOS** | 系统通知中心 | 右上角通知气泡 + 声音 |
| **Linux** | D-Bus 通知 | Freedesktop 标准通知 |
| **Windows** | Toast 通知 | 右下角弹窗 + 声音 |

**通知示例内容**：
```

价格从 ¥61.50 上升到 ¥62.00
[打开应用] [关闭]
```

## 🔔 告警系统详解 (v6.0)

### 告警类型与应用

| 类型 | 适用市场 | 说明 | 典型应用 |
|------|---------|------|---------|
| **价格告警** | A股、美股、港股 | 监控股价是否突破关键价格位 | 止损价120元、目标价150元 |
| **涨跌幅告警** | A股、美股、港股 | 监控日涨跌幅是否达到阈值 | 强势涨幅+5%、跌幅-3% |
| **成交量告警** | A股仅有 | 监控成交量是否异常 | 异常放量（日均150%）、萎靡（日均50%） |

### 触发频率与规则

| 频率模式 | 触发规则 | 使用场景 | 配置示例 |
|---------|---------|--------|---------|
| **一次性** | 条件满足立即触发，之后自动禁用 | 临时监控，只想被通知一次 | 监控利好公告发布 |
| **每日** | 每天固定检查时间，今日仅触发一次 | 日内追踪关键价位 | 每日09:35检查高点价格 |
| **每周** | 每周指定日期检查一次，周内仅触发一次 | 周度计划，定期评估 | 每周一10:00检查周开盘价 |
| **每月** | 每月指定日期检查一次，月内仅触发一次 | 月度统计，长期追踪 | 每月1号检查月初表现 |
| **自定义** | 每N天检查一次（N由用户指定） | 灵活周期，自由定制 | 每3天检查一次涨跌 |

**时间边界说明**：
- **日边界**：以市场交易时间计算，非自然日期
- **周边界**：周一-周日，触发后周内不再重复
- **月边界**：自然月份，月末自动重置

### 通知系统

**跨平台支持**：

- 🍎 **macOS**: 系统通知中心（Notification Center），支持声音和横幅
- 🐧 **Linux**: D-Bus 通知服务（freedesktop.org 标准），支持主题集成
- 🪟 **Windows**: Windows 10+ Toast 通知，右下角弹窗显示

**通知内容示例**：
```
Title: 📈 股票告警 - SH601138 (工业富联)
Body:  价格突破目标位
       当前: ¥62.50 | 目标: ¥62.00
       时间: 2026-01-19 14:35:22
```

**通知行为**：
- 触发后立即推送系统通知
- 通知包含股票代码、名称、当前价格、目标条件
- 用户可点击通知直接打开应用

### 批量操作详解

**按标签批量添加告警**

流程：
1. 选择要监控的标签（如"科技"板块的所有股票）
2. 配置统一的告警条件和频率
3. 系统自动为该标签下的所有股票添加告警

优势：
- 一次操作监控整个板块
- 避免逐个配置的繁琐
- 后续添加同标签股票自动继承配置（可选）

示例：
```
标签：科技 (包含 AAPL, MSFT, GOOGL, TSLA)
条件：涨跌幅 > +3%
频率：一次性
→ 任何科技股当日涨幅突破3%时收到通知
```

**按市场批量添加告警**

流程：
1. 选择目标市场（A股、美股、港股）
2. 配置该市场所有股票的统一告警
3. 系统应用到市场内的所有持仓/自选股票

优势：
- 市场级别统一管理
- 快速覆盖大规模持仓
- 市场特定策略一键配置

示例：
```
市场：美股 (包含所有持仓美股)
条件：价格 > 120% 昨收
频率：每日
→ 美股开盘后检查是否有高开机会
```

### 性能与限制

**性能指标**：

| 指标 | 值 | 说明 |
|------|-----|------|
| 告警检查周期 | 5秒 | 后台持续监控，每5秒检查一次条件 |
| 单个告警检查时间 | <1ms | O(1)复杂度，极高效率 |
| 1000个告警检查耗时 | ~15ms | 即使大量告警也不影响UI |
| CPU占用 | <1% | 后台占用极低 |
| 内存占用 | ~5-10MB | 告警数据存储占用很小 |

**建议使用**：
- ✅ 支持数百到数千个告警同时运行
- ✅ 可放心为所有持仓和自选股票配置告警
- ❌ 不建议超过10000个告警（内存和磁盘考虑）

### 告警管理技巧

**分层告警策略**

建议按优先级设置多层告警：
```
第1层：止损告警（一次性）
  └─ 价格低于成本价，保护本金

第2层：日度追踪（每日）
  └─ 涨幅>5%时通知，日内机会把握

第3层：周度评估（每周）
  └─ 检查是否达到周度目标

第4层：月度总结（每月）
  └─ 评估月度表现
```

**避免告警疲劳**

- 不要为每只股票都配置告警，只监控关键股票
- 采用合理的触发频率，避免频繁通知
- 定期检查并删除已实现目标的告警
- 禁用而不是删除不需要的告警，便于后续重用

**批量管理效率**

```
场景：持有30只A股，想统一设置止损告警
方式1（低效）：逐个添加 30次点击
方式2（高效）：
  1. 自选列表中为所有股票添加"持仓"标签（如已有则跳过）
  2. 按标签批量添加告警：条件=价格跌5%，频率=每日
  3. 完成！30只股票同时受保护
```

### 数据源与API

| 优先级 | API | 市场 | 用途 |
|:------:|-----|------|------|
| 1 | **腾讯 API** | A股 | 实时行情（主） |
| 2 | **新浪 API** | A股 | 实时行情（备）、分时数据（主） |
| 3 | **东方财富** | A股/港股 | 分时数据（备）、港股换手率 |
| 4 | **Finnhub** | 美股/港股 | 实时行情 |
| 5 | **TwelveData** | 美股 | 股票搜索（备） |

### 容错机制

```
A股实时数据:  腾讯 API → 新浪 API → 显示 "-"
分时数据:     新浪财经 → 东方财富 → 跳过
股票搜索:     腾讯搜索 → 新浪搜索 → TwelveData → 未找到提示
```

- **自动重试**: API 失败后自动尝试下一个数据源
- **智能选择**: 根据股票类型选择最优数据源
- **优雅失败**: 无法获取数据时显示 "-"，不影响程序运行

## 使用技巧

### 最佳使用时间

| 时间段 | 市场状态 | 数据质量 |
|--------|----------|----------|
| 09:30-15:00 | A股交易时间 | 实时数据 |
| 21:30-04:00 | 美股交易时间 | 实时数据 |
| 非交易时间 | 市场关闭 | 昨日收盘价 |

### 高效操作

- **批量管理**: 使用自选列表关注多只股票，再选择性添加到持股
- **多标签分组**: 为自选股票添加多个标签（如"科技"、"医药"）灵活分类
- **排序分析**: 利用排序功能按盈亏率、涨跌幅等维度分析表现
- **持仓识别**: 注意自选列表中高亮的持仓股票
- **分时图表**: 按 `V` 键快速查看股票分时走势
- **告警管理**: 定期检查和调整告警，避免告警疲劳

### 告警系统最佳实践

#### 1. 分层告警策略

设置多层告警，避免单一维度监控不足：

```
第1层：防线告警（一次性）
  ├─ 止损价：买入价 -5% → 保护本金
  └─ 风险提示：当月跌幅 -10% → 危险信号

第2层：日度告警（每日）
  ├─ 目标价：买入价 +10% → 日内利好确认
  └─ 开盘波动：涨幅 >3% → 日内机会

第3层：周度告警（每周）
  ├─ 周线目标 → 周度追踪
  └─ 相对表现 → 和行业比较

第4层：月度告警（每月）
  └─ 月度目标价 → 长期跟踪
```

#### 2. 避免告警疲劳

告警过多会导致"狼来了"效应，降低警觉：

```
❌ 不佳实践：
- 为所有100只自选股票都添加告警
- 为同一股票添加多个相似条件的告警
- 使用过于敏感的告警阈值（如 ±0.5%）
- 频率设置过高（每秒检查多次）

✅ 最佳实践：
- 只为关键股票添加告警（20只以内重点监控）
- 为不同目标添加告警（止损、目标价、异常波动）
- 使用合理的阈值（止损 ±3-5%、目标价 ±10%）
- 使用合适的频率（一次性、每日、每周均可）
```

#### 3. 批量管理效率

充分利用批量操作功能，提升管理效率：

```
场景：需要为所有持仓股票添加止损告警

步骤1：整理标签
  - 自选列表中为所有持仓股票添加"持仓"标签
  - 可以保留原有的行业标签，多标签不冲突

步骤2：批量添加
  - 进入告警管理 → 批量添加 → 按标签 → 选择"持仓"
  - 配置：价格告警，低于成本价5%
  - 确认应用

步骤3：持续优化
  - 新股买入时自动继承"持仓"标签
  - 自动获得止损告警，无需逐个配置
  - 周期性检查，调整阈值
```

#### 4. 市场特定策略

根据不同市场特点配置告警：

```
A股特点：
- ✓ 涨停板：容易一次性突破，用"一次性"频率
- ✓ 成交量：特别重要，配置成交量告警
- ✓ 交易时间：09:30-15:00，在此时间段设置告警

美股特点：
- ✓ 盘中波动：相对平稳，可用"每日"频率
- ✓ 财报日：易出现大幅波动，提前设置关键价位告警
- ✓ 交易时间：北京时间 21:30-04:00，避免白天频繁通知

港股特点：
- ✓ 换手率数据：从东方财富API获取，可参考
- ✓ 中资股表现：用标签分组，单独监控
- ✓ 交易时间：09:30-16:00，覆盖主午市和下午盘
```

### 数据管理

所有数据存储在本地 JSON 文件中，支持手工备份：

```bash
# 备份数据
cp -r data/ backup_$(date +%Y%m%d)/

# 恢复数据
cp backup_20260119/data/* data/
```

```
建议周期：

- 每季度：复盘整个组合，删除不需要的自选股票
- 每半年：整理标签体系，合并重复标签
```
